# Roger Rabbit's Car Toon Spin — Offline Archive

An offline copy of **Roger Rabbit's Car Toon Spin**, a ride simulator originally created by **Willby**.

## ⚠️ Credits & Disclaimer

**I did not create this simulator.**

The simulator, artwork, code, audio, and other original game assets belong to their respective original creators, including **Willby**.

This repository is an **unofficial personal/archive copy** intended to preserve and play the simulator offline.

I am not affiliated with, endorsed by, or connected to Willby, Disneyland, The Walt Disney Company, or the original attraction owners.

## 🎮 About

This project contains the files needed to run the simulator locally without relying on the original simulator webpage.

The original simulator was available through Willby's Simulators.

## 📁 Contents

* Roger Rabbit's Car Toon Spin simulator
* Original simulator JavaScript
* Artwork/assets
* Audio
* Supporting files required by the simulator

## 🛠️ How to Play

1. Download or clone this repository.
2. Open `index.html`.
3. Enjoy the simulator.

Depending on your browser, some local browser security restrictions may affect how the simulator runs.
